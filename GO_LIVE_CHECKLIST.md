# Go-Live Checklist (operativ)

## Architektur
- [ ] C4 Diagramme aktuell
- [ ] ADRs für kritische Entscheidungen dokumentiert
- [ ] Multi-Environment-Konzept (dev/stage/prod)

## Qualität
- [ ] Unit Tests
- [ ] Integrationstests
- [ ] E2E Smoke Tests
- [ ] Contract Tests

## Sicherheit
- [ ] Secret Scanning
- [ ] SAST aktiviert
- [ ] Dependency Scanning aktiviert
- [ ] DAST (mind. Stage) geplant oder aktiv
- [ ] PenTest/Review abgeschlossen

## Plattform
- [ ] CI/CD mit Quality Gates
- [ ] Reproduzierbare Infrastruktur (IaC)
- [ ] Rollback-Mechanismus verifiziert
- [ ] Datenbank-Backup/Restore getestet

## Betrieb
- [ ] Dashboards (Golden Signals)
- [ ] Alerting inkl. Eskalation
- [ ] On-Call Plan
- [ ] Incident Runbooks
- [ ] Postmortem Template

## Business
- [ ] SLA/SLO kommuniziert
- [ ] Supportprozess freigegeben
- [ ] Billing-Pfade getestet
- [ ] Rechtliche/Privacy Texte final
